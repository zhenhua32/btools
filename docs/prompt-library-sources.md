# 提示词词库整理说明

提示词分类和表达维度参考了以下官方资料，并经过重新组织、中文翻译和组合扩展；词库不是对任何网页词表的直接复制。

- OpenAI Academy: Creating images with ChatGPT
  - https://openai.com/academy/image-generation/
- Google Cloud: Imagen prompt and image attribute guide
  - https://cloud.google.com/vertex-ai/generative-ai/docs/image/img-gen-prompt-guide
- Adobe Firefly: Set camera angle for image generation
  - https://helpx.adobe.com/firefly/mobile/generate-images-with-text-to-image/customize-generated-images/set-camera-angle-for-image-generation.html
- Adobe Firefly: Writing effective text prompts for video generation
  - https://helpx.adobe.com/firefly/web/work-with-audio-and-video/work-with-video/writing-effective-text-prompts-for-video-generation.html
- Microsoft Copilot: Image prompting 101
  - https://www.microsoft.com/en-us/microsoft-copilot/for-individuals/do-more-with-ai/ai-art-prompting-guide/image-prompting-101/
- Midjourney: Prompt Basics
  - https://docs.midjourney.com/docs/prompts
- Midjourney: Art of Prompting
  - https://docs.midjourney.com/hc/en-us/articles/32835253061645-Art-of-Prompting

## 整理原则

- 每条词组同时包含自然中文和可直接用于英文模型的表达。
- 组合模板只在语义相容的词汇集合内做笛卡尔组合，避免随机拼接造成语法错误。
- 主体人物均明确为成年人。
- 不使用在世艺术家姓名、品牌名或受保护角色作为风格捷径。
- 排斥项使用明确、可执行的视觉约束，而不是模糊的“高质量”堆词。
